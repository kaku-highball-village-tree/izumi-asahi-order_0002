# izumi-asahi-order_0001

## 汎用JSON日本語可読化プログラム（変更後の仕様）

> **注意:** この節は仕様のみを示しています。プログラムはまだ実装しません。

### ファイル名

作成対象のPythonファイルは、`src`フォルダーへ次のパスで配置します。

```text
src/json_readable_Cmd.py
```

リポジトリ直下の`json_readable_Cmd.py`および`json_readable.py`は使用しません。

### 目的

UTF-8で保存された任意のJSONファイルを読み込み、Unicodeエスケープを人が
読める文字へ戻します。JSONの内容やデータ型、項目順序、配列順序および階層を
変えず、空白2文字で整形した別のJSONファイルとして保存します。

### 実行方法

```cmd
py src/json_readable_Cmd.py 入力ファイル.json
```

空白を含むパスはダブルクォーテーションで囲みます。

```cmd
py src/json_readable_Cmd.py "C:\JSON Files\sample data.json"
```

### 入力仕様

- コマンドライン引数でJSONファイルを1つだけ指定します。
- 拡張子は大文字・小文字を区別せず `.json` とします。
- 文字コードはUTF-8とし、BOMの有無を問いません。
- 最上位はオブジェクト、配列、文字列、数値、真偽値、`null` のいずれも扱います。
- 特定のファイル名、項目名または階層構造には依存しません。

### 出力仕様

- 入力と同じフォルダーへ `<入力名>_readable.json` の名前で出力します。
- UTF-8、BOMなし、空白2文字の字下げとし、末尾に改行を1つ付けます。
- 非ASCII文字は `\uXXXX` へ戻さず、そのまま読める文字で出力します。
- 元の入力ファイルは変更しません。
- 同名の出力ファイルが存在する場合は上書きせず、エラー終了します。

### データ維持仕様

- 項目名、項目順序、配列順序および入れ子構造を維持します。
- 文字列、数値、真偽値、`null`、配列およびオブジェクトの型を維持します。
- 先頭ゼロを含む文字列、日時文字列、空配列および空オブジェクトを変更しません。
- 項目の追加、削除、翻訳、並べ替えや日時変換は行いません。

### 画面表示

正常終了時は、入力ファイル、出力ファイル、最上位のJSON型を日本語で表示します。
最上位がオブジェクトまたは配列の場合は、その項目数または要素数も表示します。
`items` が配列なら要素数を表示でき、`count` と一致しない場合は警告できます。

### エラー仕様

次の場合は分かりやすい日本語メッセージを表示し、0以外の終了コードとします。

- 引数がない、または複数指定された場合
- 入力パスが存在しない、ファイルではない、または拡張子が `.json` ではない場合
- UTF-8として読み込めない場合
- JSONとして正しくない場合
- 出力ファイルがすでに存在する場合
- 権限不足などによりファイルを読み書きできない場合

正常終了時の終了コードは0とします。

### 実装方針（将来実装する場合）

- Python標準ライブラリだけを使用します。
- `main()` を作り、処理を役割ごとの関数に分け、型ヒントと日本語コメントを付けます。
- JSONの読み込みには `utf-8-sig` と `json.load()` を使用します。
- JSONの保存には `ensure_ascii=False` と `indent=2` を指定します。
- 壊れたJSONの修復、文字コード推測、複数ファイル処理、GUIおよび外部通信は行いません。
